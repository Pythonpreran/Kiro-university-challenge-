## Usage
Use the MCP fetch server to import study materials from public URLs and summarize them here.

## Example Resources
- Khan Academy: https://www.khanacademy.org
- MIT OpenCourseWare: https://ocw.mit.edu
- Coursera: https://www.coursera.org

## How to Import
1. Provide a URL to the agent
2. The agent uses the MCP fetch server to retrieve content
3. Content is summarized and added to this file
4. Resources are categorized by subject
